# Pixel/Folio — portafolio estático original

Una página de portafolio de una sola pantalla, en español, con una estética retro de terminal y píxel. El diseño, los estilos y el código de esta carpeta se hicieron desde cero; no incluye código ni recursos de 8-BitQuest.

## Personalizar

Edita `index.html` y reemplaza los textos de ejemplo: `Tu Nombre`, rol, ciudad, proyectos, herramientas y `hola@ejemplo.com`. Los estilos están en `styles.css`; el botón de tema claro/oscuro y el año automático, en `script.js`.

## Probar localmente

Abre `index.html` en un navegador. No requiere instalar dependencias ni ejecutar un servidor.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube los archivos de esta carpeta a la raíz del repositorio.
3. En **Settings → Pages**, selecciona **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.
4. Guarda y espera a que GitHub Pages publique el sitio.

Si el repositorio se llama `usuario.github.io`, también puedes abrirlo desde su dominio raíz. Para un repositorio de proyecto, GitHub Pages lo publicará bajo `https://usuario.github.io/nombre-del-repo/`.
